# Proyecto UPDS - Mi Proyecto Web

Este es un proyecto educativo para el curso de desarrollo web en UPDS.

## Contenido del Proyecto

- **Sesion2_3_JS**: Ejercicios de JavaScript básico
- **Sesion4_DOM**: Manipulación del DOM
- **Sesion5_CV _Git y GitHub**: Curriculum Vitae y control de versiones
- **Sesion6_Responsive**: Diseño web responsive
- **Sesion7_Formularios**: Formularios dinámicos con validaciones

### 🎓 Acceso GRATIS para Estudiantes

Como estudiante de UPDS, puedes obtener GitHub Copilot **completamente GRATIS** a través del GitHub Student Developer Pack:

1. 🌐 Visita: [education.github.com/pack](https://education.github.com/pack)
2. 📝 Solicita el Student Developer Pack
3. 🎓 Verifica con tu credencial de UPDS o email institucional
4. ⏱️ Espera aprobación (1-3 días)
5. ✅ ¡Disfruta de Copilot gratis mientras seas estudiante!

### 🚀 Inicio Rápido

```bash
# 1. Verifica tu acceso
Visita: https://github.com/settings/copilot

# 2. Instala en Visual Studio 2022
Extensiones → Administrar extensiones → Buscar "GitHub Copilot" → Instalar

# 3. Inicia sesión
Archivo → Configuración de cuenta → Agregar → GitHub

# 4. Activa Copilot
Herramientas → Opciones → GitHub Copilot → ☑ Enable

# 5. ¡Prueba!
Crea un archivo .js y escribe: // función para sumar dos números
```

Ver la [Guía de Inicio Rápido](./docs/QUICK_START.md) para más detalles.

## Requisitos

- Visual Studio 2022 (versión 17.4 o superior) o Visual Studio Code
- Cuenta de GitHub
- Acceso a GitHub Copilot (suscripción individual o acceso educativo)

## Cómo Empezar

1. Clona este repositorio
2. Abre el proyecto en Visual Studio o Visual Studio Code
3. Sigue las guías de configuración de Copilot en la carpeta `docs/`
