# Proyecto UPDS - Mi Proyecto Web

Este es un proyecto educativo para el curso de desarrollo web en UPDS.

## Contenido del Proyecto

- **Sesion2_3_JS**: Ejercicios de JavaScript básico
- **Sesion4_DOM**: Manipulación del DOM
- **Sesion5_CV _Git y GitHub**: Curriculum Vitae y control de versiones
- **Sesion6_Responsive**: Diseño web responsive
- **Sesion7_Formularios**: Formularios dinámicos con validaciones

## 🤖 GitHub Copilot en Visual Studio

## Requisitos

- Visual Studio 2022 (versión 17.4 o superior) o Visual Studio Code
- Cuenta de GitHub
- Acceso a GitHub Copilot (suscripción individual o acceso educativo)

## Cómo Empezar

1. Clona este repositorio
2. Abre el proyecto en Visual Studio o Visual Studio Code
3. Sigue las guías de configuración de Copilot en la carpeta `docs/`
