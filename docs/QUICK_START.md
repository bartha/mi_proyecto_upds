# Guía Rápida de GitHub Copilot

## 🚀 Inicio Rápido (5 minutos)

### 1. ¿Tienes acceso?
Verifica en: https://github.com/settings/copilot

- ✅ Si dice "Active" → Continúa al paso 2
- ❌ Si dice "Get access" → [Solicita acceso educativo gratis](./COPILOT_TEAM_GUIDE.md#-cómo-obtener-acceso-educativo-paso-a-paso)

### 2. Instalar en Visual Studio 2022

```
Extensiones → Administrar extensiones → En línea → 
Buscar "GitHub Copilot" → Descargar → Cerrar VS → 
Reiniciar VS → Listo
```

### 3. Iniciar Sesión

```
Archivo → Configuración de cuenta → Agregar → 
GitHub → Autorizar → Listo
```

### 4. Activar Copilot

```
Herramientas → Opciones → GitHub Copilot → 
☑ Enable GitHub Copilot → Aceptar
```

### 5. Probar

Crea un archivo `.js` y escribe:
```javascript
// función para sumar dos números
```

Presiona Enter y espera. Deberías ver código sugerido en gris. Presiona **Tab** para aceptar.

## ⌨️ Atajos de Teclado

| Acción | Tecla |
|--------|-------|
| Aceptar sugerencia | `Tab` |
| Rechazar sugerencia | `Esc` |
| Siguiente sugerencia | `Alt + ]` |
| Sugerencia anterior | `Alt + [` |
| Ver todas las sugerencias | `Ctrl + Enter` |

## 💡 Consejos Rápidos

### ✅ Haz esto:
- Escribe comentarios descriptivos
- Usa nombres de variables claros
- Revisa el código sugerido
- Aprende del código que genera

### ❌ Evita esto:
- Copiar sin entender
- Confiar ciegamente en todo
- Usarlo como sustituto del aprendizaje

## 🆘 Problema Común: No Funciona

### Verificar en orden:

1. ✅ ¿Tienes acceso activo? → https://github.com/settings/copilot
2. ✅ ¿VS 2022 versión 17.4+? → Ayuda → Acerca de
3. ✅ ¿Extensión instalada? → Extensiones → Administrar extensiones
4. ✅ ¿Reiniciaste VS después de instalar? → Cerrar y reabrir
5. ✅ ¿Sesión iniciada en GitHub? → Archivo → Configuración de cuenta
6. ✅ ¿Copilot habilitado? → Herramientas → Opciones → GitHub Copilot

Si todo está ✅ y no funciona → [Ver guía completa de problemas](./COPILOT_TROUBLESHOOTING.md)
